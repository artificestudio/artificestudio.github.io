# Atlas place images

Create one subfolder per Atlas place, using its ID from `content/places.js`.

Example: `assets/places/nakano-broadway/exterior.webp`.

After uploading an image, add `{ src: "assets/places/nakano-broadway/exterior.webp", caption: "Exterior", alt: "Exterior view" }` to the place's `images` array in `content/places.js`.
