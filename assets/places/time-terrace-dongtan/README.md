# Time Terrace Dongtan

This folder contains original photographs and drawings for the ARTIFICE Atlas entry `time-terrace-dongtan`.

Upload files here using GitHub → Add file → Upload files. Use simple names such as `01.webp`, `02.webp`, or `ground-floor-plan.png`.

To show them in the gallery, edit [content/places.js](../../../content/places.js) and add an `images` array to the entry `time-terrace-dongtan`:

```js
images: [
  { src: "assets/places/time-terrace-dongtan/01.webp", caption: "View of the building", alt: "Description of what the image shows" }
]
```

A photo can remain in this folder without appearing publicly in the gallery. The gallery only shows the files explicitly listed in the `images` array.
